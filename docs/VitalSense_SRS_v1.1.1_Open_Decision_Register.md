## Top unresolved implementation blockers

1. **OD-01/02/04/16 — Phase 1 capability baseline:** select metrics, sources, manual entry and supported OS/browser/device versions; attach feasibility and representative-device test evidence.
2. **OD-17 — Local data security:** choose and verify local database encryption/key management before persisting sensitive health data offline.
3. **OD-18 — Authentication/session lifecycle:** select and document the identity/session design before accepting authentication implementation.
4. **OD-07/14/15 — Export/deletion lifecycle:** approve scope, formats, store inventory, derived/cache/queue handling, backup expiry/restore reconciliation, status UX and truthful completion language.
5. **OD-10/20 — NFR and recovery targets:** approve mandatory performance, accessibility, security, reliability and backup RPO/RTO targets before the relevant release gates.
6. **OD-19 — Deployment boundary:** approve a deployment ADR that distinguishes logical modules from deployed units and records trust boundaries.
7. **OD-22 — Automation boundary:** decide n8n/application-worker responsibilities, event semantics, credentials, retries and recovery before production automation.
8. **OD-21 — AI provider and data handling:** no health data may be sent to an AI provider until provider terms, retention/training behavior, minimization, cost limits and user disclosures are reviewed.
9. **OD-03 — Phase 0 acceptance:** define measurable build/test/deployment/recovery criteria so foundation completion is objectively verifiable.

**Release rule:** A decision unresolved at a mandatory release gate blocks the affected scope unless the designated approver records an explicit, time-bounded exception with rationale, compensating controls and expiry. This register does not imply any decision has been approved.


## Merge change note

The register retains OD-01 through OD-22 and uses the detailed owner, option, risk and gate fields as the primary record. Where the main SRS and this register differ in wording, the main SRS defines normative requirements and this register records unresolved choices; neither a recommendation nor a listed test is approval evidence.
